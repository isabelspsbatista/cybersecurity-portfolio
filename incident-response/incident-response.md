# Incident Response Plan

## 📌 Overview
This project presents a structured incident response plan aligned with industry best practices, including ISO/IEC 27035 and the NIST Cybersecurity Framework. It defines processes, roles, and communication strategies to effectively manage cybersecurity incidents.

## 🏢 Business Scenario
The organization is a SaaS company relying on cloud infrastructure, web applications, and remote access to manage customer data and deliver services.

## 🔍 Key Components
- Incident classification with severity levels  
- Structured response lifecycle (Identification → Recovery)  
- Defined roles and escalation paths  
- Communication plan and stakeholder coordination  
- Testing and continuous improvement strategy
