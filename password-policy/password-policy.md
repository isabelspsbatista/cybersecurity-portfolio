# Password Policy

## 📌 Overview
This project presents a password policy designed for a small organization to improve authentication security and reduce the risk of unauthorized access.

## 📄 Full Policy Document
👉[Download Password Policy (PDF)] [Password Policy.pdf](https://github.com/user-attachments/files/26730426/Password.Policy.pdf)

## 🔐 Key Controls
- Minimum password length: 12 characters  
- Multi-factor authentication (MFA) required  
- Account lockout after failed attempts  
- Password reuse restrictions
