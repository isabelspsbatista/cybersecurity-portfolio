# Log Analysis (SOC Basics)

## 📌 Overview
This project presents a log analysis exercise focused on identifying suspicious activity within an authentication system. The objective is to analyze log data, detect potential security events, and assess risks based on observed patterns.

## 🖥️ Scenario
A web-based application generated authentication logs showing repeated failed login attempts and unusual access patterns from a single IP address, raising concerns about a potential brute-force or unauthorized access attempt.
